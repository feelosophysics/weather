# 우리 날씨

광고 없이 큰 글씨로 오늘·열흘 예보와 한 달 경향을 보는 가족용 웹앱입니다. HTML·CSS·JavaScript와 Node.js 기본 기능만 사용하며 외부 패키지 설치나 빌드가 필요하지 않습니다.

## 현재 제공 범위

- **한 달 경향: 실제 기상청 1개월 전망 XML 연동.** 권역별 4주의 평균기온·강수량 확률, 평년 범위, 전국 해설을 표시합니다.
- **오늘 / 시간별 / 열흘: Open-Meteo 일반 예보 API 직접 연동.** 가입·인증키 없이 브라우저에서 요청합니다. 현재값은 관측소 실측이 아닌 모델 추정이며 서울·부산·제주시 대표 좌표를 지원합니다.
- 권역·글씨 크기 설정 저장, PWA 설치 안내, 오프라인 파일 저장.
- **내 동네 저장:** 한국 지명을 검색하고 시·군·구를 확인해 최대 5곳 저장·전환·삭제합니다. 저장된 목록과 선택값은 각 기기의 브라우저 localStorage에만 보관합니다. 공개 소스나 서버 파일에 저장하거나 다른 기기와 동기화하지 않습니다. 기본 도시도 삭제할 수 있으며 마지막 한 곳은 남겨둡니다.
- 로그인·광고·추적 SDK·외부 글꼴·GPS·상시 백그라운드 갱신 없음.

자료는 발표 시점의 전망이며 날짜별 한 달 예보가 아닙니다. 강수량 전망 확률은 비가 올 확률과 다릅니다. 다음 발표 예정 시각이 지나면 이전 발표 자료임을 표시합니다.

## 로컬 실행

Node.js 22 이상에서:

```powershell
cd C:\Users\alzznd\Desktop\newlearn\projects\weather
npm run dev
```

http://127.0.0.1:4173 을 엽니다. 종료는 Ctrl+C입니다. Node.js가 파일을 제공할 뿐 외부 서버나 별도 설치 패키지가 필요하지 않습니다. 기본 상태에서는 이 컴퓨터에서만 접속할 수 있습니다.

같은 와이파이에서 폰으로 **화면 확인**이 필요할 때만 `npm run dev -- --lan`을 사용하고, 컴퓨터 사설 IP와 4173 포트로 접속합니다. 방화벽·공유기에 따라 연결이 제한될 수 있습니다. 일반 사설 IP의 HTTP에서는 PWA 설치가 제한됩니다. 실제 폰 설치는 HTTPS로 배포한 뒤 확인합니다.

## 오늘·열흘 예보

앱을 열거나 도시를 바꿀 때 Open-Meteo에 필요한 항목만 요청합니다. 같은 도시 자료는 20분간 기기에서 재사용하고, 수동 갱신도 최소 1분 간격으로 제한합니다. 상시 폴링이나 백그라운드 작업은 없습니다. 실패 시 이전 자료와 기준·수집 시각을 표시하며, 7일 이상 된 캐시는 사용하지 않습니다. 누락값은 0 대신 `—`로 표시합니다.

요청은 선택 도시의 공개 대표 좌표를 사용합니다. GPS 권한은 요구하지 않지만, 직접 접속하므로 서비스 운영자에게는 요청 IP와 선택 좌표가 전달됩니다. 계정·키·쿠키를 보내지 않고 요청에 사이트의 referrer도 보내지 않습니다.

저장한 동네는 검색 결과의 대표 좌표를 사용합니다. 검색어는 사용자가 검색 버튼을 눌렀을 때만 Open-Meteo 지명 검색 서비스로 전송합니다. 지명 데이터는 GeoNames 기반으로, 일부 국내 읍·면·동은 누락되거나 로마자로 반환될 수 있습니다. 시·군·구와 검색 원문을 확인한 뒤 저장합니다. 브라우저 데이터 삭제나 사이트 주소 변경 시 저장 목록이 사라질 수 있으며 자동 백업은 없습니다. 실제 집 주소를 소스·설정 기본값·테스트 자료로 넣지 않습니다.

기본 제공 모드는 Open-Meteo `best_match`입니다. 지역에 따라 제공처가 정한 모델 조합이며, 부모님 동네에서 정확도가 가장 높다는 자체 검증은 아직 없습니다. `dist/forecast.js`에 요청과 정규화 로직을 분리했습니다. 구글 WeatherNext나 ECMWF AIFS와의 비교·전환 기능은 아직 구현하지 않았습니다.

데이터 출처와 CC BY 4.0 링크, 표시 변환 사항을 화면에 표시합니다. 가족용 비상업적 이용으로 무료 API를 사용하며 상업 배포 전에는 이용 조건을 다시 확인합니다.

## 한 달 전망 자료 갱신

```powershell
npm run refresh
```

공식 RSS 안내에서 현재 1개월 전망 XML 주소를 찾아 `dist/data/month.json`을 갱신합니다. 인증키가 필요하지 않습니다. 최근 수집 1시간 내에는 파일을 재사용하며, 강제 확인은 `npm run refresh -- --force`입니다. XML 인코딩, 지역명, 네 주의 필드와 확률 합계를 검증한 뒤 교체합니다. 오류나 더 오래된 발표가 반환되면 기존 파일을 유지하고 실패를 보고합니다.

현재는 **수동 갱신**입니다. 개발 서버 실행이나 앱 열기만으로 기상청에 접속하지 않습니다. 배포판 갱신은 자료 수집 후 사이트 파일을 다시 배포해야 합니다. 자동 수집·배포는 아직 설정하지 않았습니다.

한 달 전망에서 브라우저는 같은 사이트의 작은 JSON만 읽습니다. XML 응답에 브라우저용 교차 출처 허용 헤더가 없어도 이 구조는 동작합니다. 앱은 발표 시각·수집 시각을 표시하며 네트워크가 끊기면 저장 자료라는 안내가 나옵니다.

## 기상청 단기·중기예보를 추가할 경우

현재 Open-Meteo 구성에는 필요하지 않습니다. 기상청 공식 단기·중기예보로 비교하거나 전환할 경우 아래 두 서비스의 활용 신청과 서비스키 발급이 필요합니다. 공식 목록은 무료·자동승인·출처표시 제1유형으로 안내합니다. 서비스 응답·승인 상태는 키 발급 후 실제 호출로 재확인해야 합니다.

- [기상청 단기예보 조회서비스](https://www.data.go.kr/data/15084084/openapi.do): 실황·시간별예보.
- [기상청 중기예보 조회서비스](https://www.data.go.kr/data/15059468/openapi.do): 중기 육상예보·기온.

키를 대화나 프런트엔드에 넣지 않습니다. 후속 수집 스크립트에서 로컬 환경변수 또는 배포 서비스의 비밀 설정을 사용하도록 연결합니다. 현재 키를 읽는 코드나 단기·중기 API 어댑터는 아직 추가하지 않았습니다. API허브 키와 공공데이터포털 키는 별개입니다.

키 없는 단기·중기 RSS는 2025-03-31 중단 공지가 있으므로 사용하지 않습니다. 날씨누리 화면 내부의 비공개 인터페이스를 우회하지 않습니다.

## 배포 구조

배포 주소: https://feelosophysics.github.io/weather/

`.github/workflows/pages.yml`이 `main` 푸시 또는 수동 실행 시 문법 검사, 한 달 전망 갱신 시도, 테스트를 거쳐 `dist/`만 GitHub Pages에 배포합니다. 기상청 갱신에 실패하면 경고를 남기고 원래 발표 시각을 유지한 저장 자료로 배포합니다. 정기 갱신 일정은 설정하지 않았습니다.

휴대폰 Chrome 또는 삼성 인터넷에서 배포 주소를 연 뒤 메뉴의 **앱 설치** 또는 **홈 화면에 추가**를 선택합니다. 메뉴 문구는 브라우저 버전에 따라 다릅니다. 홈 화면 아이콘으로 열어 주소창 없는 실행과 동네 저장 유지 여부를 확인합니다. PC 로컬 주소의 저장 목록은 배포 주소로 이전되지 않으므로 폰에서 동네를 새로 등록합니다.

`dist/`가 빌드가 필요 없는 웹앱 소스입니다. 상대 경로를 사용하므로 GitHub Pages의 `/weather/` 같은 하위 경로도 지원하도록 작성했습니다. 배포 전 실제 하위 경로와 휴대폰 설치는 검증해야 합니다. 정적 호스팅만으로 화면과 저장된 전망을 제공할 수 있습니다. 실시간 중계 서버 대신 별도 수집 작업으로 JSON을 갱신하는 방식을 우선합니다.

## Git 저장소 경계

이 폴더는 독립 저장소입니다. 상위 `newlearn` 저장소는 `/projects/`를 제외하므로 이 프로젝트의 파일을 추적하지 않습니다. 두 저장소 사이의 자동 병합이나 커밋 공유는 없습니다.

- Git 명령은 이 폴더에서 실행하거나 `git -C C:\Users\alzznd\Desktop\newlearn\projects\weather ...`로 대상을 지정합니다.
- `.gitignore`의 `!/dist/` 예외는 정적 웹앱 소스를 추적하기 위한 것입니다.
- `.env`, `.env.*`는 제외합니다. 민감한 키는 `dist/` 어디에도 넣지 않습니다.
- 커밋·푸시는 별도 요청 시 실행합니다.
